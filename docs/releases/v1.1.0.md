## What's new

JClean now runs on **Windows** and **Linux**, with the same safety rules as on the Mac.

**Windows 10 and 11**

- Finds temporary files, crash dumps, the Recycle Bin, browser and app caches, and every developer cache the Mac version knows about.
- Clears Windows Update downloads, the Delivery Optimization cache and old versions of Windows components, and removes a previous Windows installation (Windows.old) with Windows' own Disk Cleanup. These ask for administrator approval once per clean.
- Never downloads OneDrive files that are only in the cloud, and never follows links out of the folders it cleans.
- Mica behind the sidebar on Windows 11.

**Linux**

- Finds `~/.cache`, the Trash, thumbnails, Flatpak and Snap app caches, and the developer caches.
- Clears the APT or DNF package cache, trims the system journal to the last two weeks, removes old Snap versions, and finds data left behind by Flatpak apps you've uninstalled. System items ask for your password once per clean.

**Everywhere**

- Buttons have stronger contrast, so their text is easier to read.
